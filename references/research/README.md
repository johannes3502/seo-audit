# Research index

Read only what the task needs. The files are written for an agent that must
apply the rules to a codebase, not for a search-engine trivia quiz.

| File | Use it for |
|---|---|
| `00-sources.md` | primary sources and checked dates |
| `01-search-essentials.md` | eligibility, spam, E-E-A-T, limits of evidence |
| `02-rendering.md` | SSR/SSG/CSR/hybrid, hydration, framework pitfalls |
| `03-indexing.md` | robots, canonical, sitemap, redirects, status codes, mobile |
| `04-onpage-keywords.md` | intent, title, description, headings, links, cannibalization |
| `05-content-eeat.md` | helpful content, trust, AI-generated content |
| `06-performance.md` | LCP/INP/CLS and code-level performance checks |
| `07-structured-data.md` | JSON-LD types, fields, validation |
| `08-internationalization.md` | hreflang, locale URLs, x-default |
| `09-ai-search.md` | AI Overviews/AI Mode, `llms.txt` correction |
| `10-frameworks.md` | where SEO lives in each supported stack |
| `11-measurement.md` | GSC, field data, evidence hierarchy |

The checklists in `../checklists/` turn these rules into a review sequence.
If a source changes, update the research file and the rule catalog together.
